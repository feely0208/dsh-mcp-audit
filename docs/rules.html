深鲸守护 · MCP 服务安全 —— 4 条规则
 
[high] MCP-UNPINNED-NPX
MCP 服务用 npx -y 拉未锁定版本的远端包
依据：MCP 官方文档 · Server 部署建议；npm Docs — npx `-y` 跳过确认；供应链安全通用实践（锁定版本 + 完整性校验）
 
[high] MCP-PLAINTEXT-URL
MCP 端点使用明文 http://
依据：GB/T 22239-2019 第三级 · 安全通信网络 · 通信传输 —— 应保证通信过程中数据的完整性与保密性；MCP 官方文档 · 传输安全
 
[medium] MCP-LOCAL-EXEC
MCP 服务指向本地可执行文件或脚本
依据：MCP 官方文档 · Server 生命周期；最小权限原则 —— 应限制可执行程序的运行
 
[low] MCP-NO-CONFIG
仓库里找不到 MCP 配置
依据：MCP 官方文档 · 配置位置（各客户端不同：claude_desktop_config.json / .mcp.json / settings.json）
